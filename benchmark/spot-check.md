## Failure patterns

In order of how many rows they cost:

1. Findings are emitted even when the tool itself concludes that no caller is affected. (rows 4, 5, 12, and the internals-only rows)
2. Comment and docstring edits count as changes. (rows 1, 2, 13)
3. Return-value changes are missed by the "internals only" label, because only return expressions are compared, not how the returned value is built. (rows 8, 10)
4. Name-based method resolution picks the wrong class. (row 11)
5. Protocol signatures are treated as runtime contracts. (row 6)
